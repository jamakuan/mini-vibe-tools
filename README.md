# Mini Vibe Tools

這個小專案提供以易經為靈感的互動工具，透過使用者輸入的三個數字與心中問題，提供卦象指引與建議。

## 使用方式
1. 在頁面輸入想詢問的問題或情境。
2. 填寫三個 0-999 的直覺數字。
3. 點擊「解卦」即可取得卦象名稱、含義與行動建議。
4. 若需要靈感，可點擊「生成提問靈感」獲取隨機情境。
5. 系統會將三個數字加總後以 64 為除數取餘，依餘數對應 64 卦，符合易經「以除取餘定卦」的思路。
